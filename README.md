
# Scholars'Haven CBT Quiz App

A simple web-based CBT platform for Scholars'Haven students. 
Students can practice JAMB-style questions for Maths, English, and Physics with timer and instant results.

## Features
- Student login with name + phone
- 3 Subjects: Maths, English, Physics
- 3-minute timer per subject
- Auto-grading and instant results
- Admin panel to view all results

## How to Run Locally
1. `pip install -r requirements.txt`
2. `python app.py`
3. Open http://127.0.0.1:5000

## Admin Panel
Link: `/admin` 
Password: set in `app.py`
